# Mystia Helper

แอปตัวช่วยสำหรับเกม Touhou Mystia's Izakaya สร้างด้วย Tauri 2 + React + TypeScript

## ฟีเจอร์

- **ลูกค้าแรร์**: เลือกลูกค้าและ tag ที่ลูกค้าขอ แล้วแอปจะแนะนำชุดอาหาร วัตถุดิบที่ควรเติม และเครื่องดื่ม พร้อมเรตติ้งที่คาดว่าจะได้และสถานะงบ
  - แสดงวัตถุดิบทดแทนที่ให้ผลเหมือนกัน, ชุดวัตถุดิบเติมแบบอื่นที่ได้เรตติ้งเท่ากัน และเครื่องดื่มอื่นที่ได้ผลเท่ากัน
  - มีแถบลูกค้าในร้าน: กด "+ เพิ่มลูกค้า" เมื่อลูกค้าเข้ามา (มาจากโซนไหนก็ได้) คลิกแท็บเพื่อสลับ และกด × เมื่อลูกค้ากลับ แต่ละคนจำออเดอร์และชุดที่ปรับเองไว้แยกกัน
  - ปุ่ม tag อาหารแสดงประโยคที่ลูกค้าพูดตอนสั่ง tag นั้น (จาก wiki)
  - กด 📌 ที่ชุดอาหาร (หรือในแผงจัดชุดเอง) เพื่อปักหมุดไว้ในแถบขวา จัดกลุ่มตามลูกค้าและคิดเรตติ้งตามออเดอร์ล่าสุด แถบลูกค้าตรึงไว้บนจอได้ด้วยปุ่ม 📌 ท้ายแถบ และปุ่ม "ล้างคืนนี้" ล้างลูกค้าในร้านกับชุดที่ปักหมุด
  - แถบขวามีรายการวัตถุดิบเติมที่ให้ tag ที่ลูกค้าคนนั้นชอบ และรายการเครื่องดื่ม
  - แสดงสเปลการ์ดรางวัล (เรตติ้งชมพู) และบทลงโทษ (เรตติ้งดำ) ของลูกค้าคนนั้น พร้อมคำอธิบายจาก wiki
  - เลือก tag อาหารและเครื่องดื่มครบแล้ว ใบออเดอร์จะยุบเหลือแถบเดียวให้เห็นชุดอาหารทันที กด "แก้ออเดอร์" เพื่อเปิดใหม่
  - แถบ "คืนนี้" ใต้แถบลูกค้าใช้ร่วมกันทุกคน: Trend อุปกรณ์ และสวิตช์ไม่เช็คคำขอ
  - เลือก Trend ที่ฮิต/ไม่ฮิตตอนนี้ได้หลาย tag (ดูจากหนังสือพิมพ์ในเกม) แอปจะคิดแต้มให้ลูกค้าที่ชอบหรือไม่ชอบ Trend
  - เลือกอุปกรณ์ทำอาหารที่ใช้ได้คืนนี้ แอปจะแนะนำเฉพาะสูตรที่ทำด้วยอุปกรณ์เหล่านั้น
  - เลือกเป้าหมาย (สมดุล, ประหยัดของ, กำไรต่อออเดอร์, ทำเร็ว, ให้ลูกค้าอยู่นาน) แต่ละเป้าหมายคือชุดน้ำหนักของปัจจัย (กำไรจาน, ต้นทุน, ความหายากของวัตถุดิบและเครื่องดื่ม, เวลาทำ, ราคารวม, จำนวนวัตถุดิบที่เติม, งบ) ชุดอาหารเรียงตามเรตติ้งก่อน แล้วตามคะแนนความคุ้มค่า 0–100 ที่กดดูรายละเอียดรายปัจจัยและคะแนนตามเป้าหมายอื่นได้
  - แต่ละชุดแสดงต้นทุนโดยประมาณ (มูลค่าใน wiki ของวัตถุดิบรวมเครื่องดื่ม) กำไรจาน เลเวลของสูงสุด และเวลาทำ
  - เรียงผลลัพธ์แบบอื่นได้ตามราคา กำไร ต้นทุน เลเวลของ แต้ม จำนวนวัตถุดิบที่เติม เลเวลสูตร เวลาทำ หรือชื่อ
  - กด "ปรับเอง" เพื่อจัดชุดเอง: เพิ่ม/เอาวัตถุดิบออก เปลี่ยนเครื่องดื่ม และดูว่าวัตถุดิบแต่ละอย่างจะเพิ่ม tag อะไรและเปลี่ยนแต้มเท่าไร
- **ความคืบหน้า**: ติ๊กสูตร เครื่องดื่ม วัตถุดิบ และโซนที่ปลดล็อกในเกมแล้ว เมื่อเปิดใช้ ตัวช่วยจะคำนวณจากสิ่งที่ปลดล็อกแล้วเท่านั้น
- **ข้อมูลเกม**: ดูข้อมูลพร้อมภาพจาก wiki และแก้ค่าที่ไม่ตรงกับในเกมได้ (บันทึกเฉพาะค่าที่แก้ คืนค่าเป็นของ wiki ได้)
- **ตั้งค่า**: เลือกภาษา (ไทย/English สลับได้ที่ปุ่ม TH/EN ด้านล่างแถบซ้ายด้วย) เลือก DLC ที่มี เปิด/ปิดคอลแลบแต่ละอัน (แขก สูตร และเครื่องดื่มของคอลแลบที่ปิดจะไม่ถูกแนะนำ) และสำรอง/นำเข้าความคืบหน้ากับข้อมูลที่แก้

กฎการคำนวณอยู่ใน [docs/game-mechanics.md](docs/game-mechanics.md)

## การพัฒนา

ต้องมี Node.js, Rust และ Visual Studio Build Tools (C++)

```bash
npm install
npm run images      # ดาวน์โหลดภาพจาก wiki ลง public/images/ (ไม่ได้เก็บใน git) ข้ามได้ถ้าไม่ต้องการภาพ
npm run tauri dev   # เปิดเป็นแอปเดสก์ท็อป
npm run dev         # เปิดในเบราว์เซอร์ที่ http://localhost:1420
npm test            # unit test ของตัวคำนวณ
npm run tauri build # สร้างไฟล์ติดตั้ง
```

## ข้อมูลเกม

ข้อมูลมาจาก Lua data module ของ [Touhou Mystia's Izakaya Wiki](https://touhou-mystias-izakaya.fandom.com) ผ่าน MediaWiki API

```bash
npm run data:fetch  # ดาวน์โหลด module ล่าสุดลง data/wiki-raw/
npm run data:build  # แปลงเป็น src/data/gamedata.json และเขียนรายงานที่ data/wiki-report.md
npm run data:images # จับคู่ไอคอนและภาพลูกค้ากับ item บน wiki ใหม่ (เขียน data/wiki-raw/images.json) แล้วรัน data:build อีกครั้ง
npm run data:pages  # ดึงคำพูดตอนขอ tag อาหารและสเปลการ์ดจากหน้าลูกค้าแรร์ (เขียน data/wiki-raw/customer-pages.json) แล้วรัน data:build อีกครั้ง
```

ภาพจากเกมไม่อยู่ใน git (`public/images/` อยู่ใน `.gitignore`) `npm run images` ดาวน์โหลดเฉพาะไฟล์ที่ `src/data/gamedata.json` อ้างถึงและยังไม่มีในเครื่อง

`data:build` จะแก้ชื่อ tag/สถานที่ที่สะกดไม่ตรงกันบน wiki และบันทึกทุกจุดที่แก้ไว้ในรายงาน

## เว็บ

เปิดใช้ได้ที่ https://mystia.varot.me (GitHub Pages) push เข้า `main` แล้ว `.github/workflows/deploy.yml` จะรันเทสต์ build และ deploy ให้เอง ความคืบหน้ากับค่าที่แก้เก็บใน localStorage ของเบราว์เซอร์นั้น ๆ ย้ายเครื่องให้ใช้สำรอง/นำเข้าในหน้าตั้งค่า

ตอน build บน GitHub workflow จะดาวน์โหลดภาพจาก wiki และเก็บไว้ใน Actions cache ถ้า wiki ล่มตอนที่ cache ยังไม่มีภาพ deploy จะล้มและเว็บเดิมยังอยู่

ถ้าต้องการเว็บที่ไม่มีภาพจากเกม ให้ build ด้วย `VITE_HIDE_IMAGES=1` แอปจะแสดงตัวอักษรย่อแทนภาพ และไม่มี `dist/images` ในผล build บน GitHub ให้ตั้ง repository variable `HIDE_IMAGES` เป็น `1` (Settings → Secrets and variables → Actions → Variables) แล้วรัน workflow ใหม่

## สัญญาอนุญาต

- **ข้อมูลเกม** (`data/wiki-raw/`, `data/wiki-report.md`, `src/data/gamedata.json`) ดัดแปลงจาก [Touhou Mystia's Izakaya Wiki](https://touhou-mystias-izakaya.fandom.com) ซึ่งใช้ [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) ไฟล์เหล่านี้จึงเผยแพร่ภายใต้ CC BY-SA 3.0 เช่นกัน
- **ภาพ** ที่เว็บแสดง (ดาวน์โหลดจาก wiki ตอน build ไม่ได้อยู่ใน repo นี้) เป็นลิขสิทธิ์ของผู้พัฒนาเกม (二色幽紫蝶, Re零同人社) และ 上海アリス幻樂団 ไม่อยู่ภายใต้ CC BY-SA หากเจ้าของสิทธิ์ต้องการให้นำออก แจ้งได้ที่ issue ของ repo นี้
- Mystia Helper เป็นเครื่องมือแฟนเมด ไม่เกี่ยวข้องกับผู้พัฒนาหรือผู้จัดจำหน่ายเกม
